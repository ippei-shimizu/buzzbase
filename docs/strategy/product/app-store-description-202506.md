## 概要文（本文）

BUZZ BASEは、野球の個人成績を記録・管理し、仲間とランキング形式で競い合える野球成績アプリです。

打率や防御率の計算はアプリにおまかせ。試合結果を入力するだけで、29種類の成績指標を自動で算出します。さらに、1打席ごとの打球方向や対戦投手まで記録できる詳しい打席記録と、自分の打撃を多角的に振り返れる成績分析機能を搭載。グループ機能を使えば、チームメイトやライバルと成績をランキングで比較できます。

中学・高校・大学の野球部員から草野球プレーヤーまで、すべての野球人のための成績管理アプリです。

-- 主な機能 --

【試合結果の記録】
「打撃・投球の両方」「打撃のみ」「投球のみ」から記録パターンを選んで、試合ごとに成績を記録できます。対戦相手、スコア、打順、守備位置に加えて、球場の記録にも対応。点数はワンタップのステッパーで手早く入力できます。

【1打席ごとの詳しい打席記録】
ステップ式の入力画面で、打席結果をタップするだけのカンタン記録。グラウンドのイラストをタップして打球方向を残せるほか、最終カウント・初球打ち・ランナー状況などの詳細データや、対戦した相手投手（利き腕・投手タイプ・球速帯など）も記録できます。詳細は後からの追記・編集もOK。三振は空振り・見逃しの区別まで残せます。

【29種類の成績を自動計算】
打率・出塁率・長打率・OPS・ISO・ISOD・BB/K・盗塁成功率など打撃14指標、防御率・WHIP・K/9・BB/9・K/BB・勝率など投手15指標を自動で算出。面倒な計算は一切不要です。

【打撃成績の詳細分析】
記録した打席データをもとに、自分の打撃を多角的に分析できます。
・打球分布図（スプレーチャート）で打球の傾向をひと目で確認
・方向別の打率をヒートマップで可視化
・得点圏打率・走者状況別の成績
・初球・有利カウント・追い込まれた場面など、カウント別の成績
・球種別の得意・苦手や、対戦投手別の成績
・打率・出塁率・長打率などの推移グラフ（年・月・日・試合ごとに切り替え）
年度・試合種別でのフィルタリングにも対応しています。

【成績ページ】
打球分布図・打席内訳チャート・防御率推移グラフで、自分の成績を詳しく分析。年・月・日ごとの成績一覧表で、試合ごとの調子の波も把握できます。年度・試合種別でのフィルタリングにも対応。

【ダッシュボード】
自分の打撃成績・投手成績のサマリーをひと目で確認。レーダーチャートで自分の強み・弱みを視覚的に把握できます。年度・シーズン・試合種別ごとにフィルタリングも可能。

【グループランキング機能】
チームメイトや野球仲間でグループを作成し、打率・打点・本塁打・防御率・奪三振などの成績をランキング形式で比較できます。同じチーム内はもちろん、他チームのライバルとも競い合えます。年度・試合種別でのフィルタリングにも対応。

【招待コードでグループ招待】
招待コードをLINEなどで共有するだけで、アプリ未登録の友達もグループに招待できます。アプリをインストールしてコードを入力すれば、すぐにグループに参加できます。

【シーズン管理】
年度やシーズンごとに成績を分けて管理。公式戦・オープン戦の区別も可能。シーズンを振り返りながら、自分の成長を実感できます。

【試合結果一覧】
すべての試合記録を一覧で確認。対戦相手で検索したり、日付・シーズン・試合種別でフィルタリングできます。

【プロフィール】
ポジション・チーム情報・受賞歴を登録して、自分の野球プロフィールを作成。成績とあわせて他のユーザーに公開できます。

【フォロー機能】
気になる選手やチームメイトをフォロー。フォローしたユーザーの成績をチェックできます。

【野球ノート】
試合の振り返りや練習メモを記録。成績データとあわせて、自分の課題や気づきを書き留められます。

【通知機能】
フォローやグループ招待の通知をリアルタイムで受け取れます。

【プライバシー設定】
非公開アカウントに設定すれば、承認したフォロワーだけが成績を閲覧できます。

## 今回ブラッシュアップした主なポイント

- **冒頭リード文**: 「1打席ごとの打球方向や対戦投手まで記録できる詳しい打席記録」「打撃を多角的に振り返れる成績分析」を訴求点として追加。
- **【試合結果の記録】**: 記録パターン分岐（両方 / 打撃のみ / 投球のみ）、球場の記録、点数のステッパー入力を反映。
- **【1打席ごとの詳しい打席記録】（新設）**: ステップ式入力 / グラウンドタップによる打球方向 / 打席詳細データ（最終カウント・初球打ち・ランナー状況）/ 相手投手の記録 / 三振の空振り・見逃し区別 を訴求。
- **【打撃成績の詳細分析】（新設）**: スプレーチャート、方向別ヒートマップ、得点圏・走者状況別、カウント別、球種別・対戦投手別、推移グラフを列挙。
- **【こんな人におすすめ】**: 「打球方向・対戦投手まで残したい」「打撃のクセを分析したい」層を追加。

> 注: 既存の【成績ページ】セクションは現行の文言を維持している。【打撃成績の詳細分析】と内容が一部重複するため、ストア掲載時はどちらかへ統合するか、【成績ページ】を投手成績・推移グラフ寄りの記述に絞ると重複感を避けられる。
