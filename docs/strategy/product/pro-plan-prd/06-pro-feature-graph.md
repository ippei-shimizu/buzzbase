## ⚠️ 設計方針の更新（2026-06-27）

本 PRD は当初「新規画面＋新API（`/stats/season_transition`）」を前提に書かれたが、Pro設計後に
**試合/月単位の推移グラフが既に実装された**（打撃: `BattingTrendChart` 4ライン、投手: `EraTrendChart` 月単位防御率）。
そのため本機能は **新規画面を作らず、既存チャートを拡張する** 方針に変更する。

- 打撃: `BattingTrendChart` に **粒度「シーズン」を追加**（実装済みの粒度は 試合 / 月 / 年 / シーズン / 直近10 の5種。シーズン以外は無料で提供済み）
- 投手: `EraTrendChart` に粒度切替を新設（**実装は 月 / シーズン の2種のみ**。試合 / 年 粒度は未実装）
- 自己ベスト強調: **mobile のみ実装**（打撃は シーズン / 年 粒度で OPS 最高値、投手は シーズン粒度で ERA 最小値をキャプション表示）。front は未実装
- 置き場: 既存 **成績タブ**（新規 Pro 画面は作らない）
- 無料 / Pro 境界（2026-06-27 再確定）:
  - **無料据え置き**: 試合 / 月 / 年 / 直近10（打撃・投手とも既存は無料。年を Pro 化するとリグレッションになるため据え置く）
  - **Pro**: シーズン粒度（春/夏/秋季）＋ 自己ベスト強調

以下の指標一覧・計算式・集計ロジック・自己ベスト検出は引き続き有効。UI/API は上記方針に合わせて読み替えること。

## 概要

複数シーズンを跨いだ自分の成績推移を折れ線グラフで可視化する Pro 機能。
「3年前と比べて確実に成長している」という自己肯定感を生み、JTBD「成長実感」「諦めない」を支える。
実装は新規画面ではなく、既存の打撃/投手推移グラフへの**粒度（シーズン/年）拡張**として行う。

---

## 背景・目的

- 戦略ドキュメントのステップ11 で MVP に採用
- ペルソナ全員の共通動機「データで成長を可視化したい」に直撃
- 既存DBのデータのみで実装可能（新規データ不要）
- 既存の `seasons` テーブルを活用

## 表示する指標一覧

### 打撃指標

| 指標 | 計算式 | 既存DB | 実装 |
|----|------|----|----|
| 打率 | 安打 / 打数 | batting_averages | ◎ |
| 出塁率 | (安打+四球+死球) / (打数+四球+死球+犠飛) | 同上 | ◎ |
| 長打率 | 塁打 / 打数 | 同上 | ◎ |
| OPS | 出塁率 + 長打率 | 同上（計算で算出） | ◎ |
| ISO | 長打率 - 打率 | 同上 | 未 |
| BB/K | 四球 / 三振 | 同上 | 未 |
| 本塁打数 | 本塁打 | 同上 | 未 |
| 打点 | 打点 | 同上 | 未 |

### 投手指標

| 指標 | 計算式 | 既存DB | 実装 |
|----|------|----|----|
| 防御率 | 自責点 × 9 / 投球回 | pitching_results | ◎ |
| WHIP | (被安打+与四球) / 投球回 | 同上 | 未 |
| K/9 | 奪三振 × 9 / 投球回 | 同上 | 未 |
| BB/9 | 与四球 × 9 / 投球回 | 同上 | 未 |
| K/BB | 奪三振 / 与四球 | 同上 | 未 |
| FIP | 簡易計算式 | 同上 | 未 |
| 勝率 | 勝利 / (勝利+敗戦) | 同上 | 未 |

※ US-02 の「WHIP・防御率・K/BB を同時に折れ線表示」は未実装。現状の推移グラフは防御率のみ。

## データモデル

### 既存テーブルを活用（新規テーブル不要）

- `seasons` テーブル → X軸のラベル
- `batting_averages` テーブル → 打撃指標
- `pitching_results` テーブル → 投手指標
- `match_results` テーブル → 紐付け

### 集計クエリ例

```ruby
class SeasonStats
  def self.batting_for_user(user_id, season_id)
    BattingAverage
      .joins(game_result: :match_result)
      .where(user_id: user_id, game_results: { season_id: season_id })
      .group('game_results.season_id')
      .select(
        'SUM(hit) as total_hit',
        'SUM(times_at_bat) as total_at_bat',
        'SUM(base_on_balls) as total_bb',
        'SUM(strike_out) as total_so',
        # ...
      )
  end

  def self.batting_average(stats)
    stats.total_hit.to_f / stats.total_at_bat
  end

  def self.ops(stats)
    obp(stats) + slg(stats)
  end
end
```

## API 設計

専用の `season_transition` エンドポイントは作らず、既存の推移グラフ API に `granularity=season` を追加した。

### GET /api/v2/stats/batting_trend

クエリパラメータ:
- `granularity`: `game`（既定・累積）/ `month` / `year` / `season` / `recent_games`（直近10試合）
- `user_id`（省略時は自分）/ `year` / `match_type` / `season_id` / `tournament_id` / `start_month` / `end_month`

### GET /api/v2/stats/era_trend

クエリパラメータ:
- `granularity`: `month`（既定）/ `season`
- `user_id` / `year` / `season_id` / `tournament_id` / `start_month` / `end_month`

### 共通の仕様

- `granularity=season` は entitlement `season_transition_graph` が必要。未加入は **403** `{ "error": "シーズン推移は Pro プラン限定です" }`
- `granularity=season` のときは `season_id` を無視する（シーズン跨ぎ比較が1シーズンに縮退するため）
- 非公開アカウントの他ユーザーを指定した場合は 403

レスポンス（共通形）:
```json
{
  "granularity": "season",
  "points": [
    { "key": "season-1", "label": "2024年春季", "batting_average": 0.285, "on_base_percentage": 0.352, "slugging_percentage": 0.401, "ops": 0.753 }
  ]
}
```

`era_trend` の points は `{ key, label, era }`。自己ベストは API では返さず、クライアント側で `points` から算出する。

## エッジケース・エラーハンドリング

| ケース | 対応 |
|------|----|
| シーズンデータが1個のみ | 自己ベストのキャプションは出さない（`points.length > 1` のときのみ表示） |
| シーズン未割り当ての試合 | 集計対象外（`seasons` を INNER JOIN） |
| 投手データなし（野手のみ） | 投手タブを非表示 |
| データ欠損のシーズン | グラフで点として表示せずスキップ |
| 投球回 0 のシーズン | 防御率・WHIP は計算しない |
| 打数 0 のシーズン | 打率等は計算しない |
