# App Store スクリーンショット

App Store Connect に登録するスクリーンショットと、それを生成するスクリプトを置く。

## ディレクトリ

| パス | 中身 |
| ---- | ---- |
| `v1/` | 2026-09 時点で公開中のスクリーンショット 5 枚。mobile 2.0.0 以前の UI |
| `captures/` | シミュレータで撮った生の画面キャプチャ。`build.py` の入力 |
| `v2/` | `build.py` の出力。App Store Connect にはこれを登録する |
| `build.py` | 生キャプチャに端末フレーム・背景・文言を合成する |

## 使い方

```bash
cd assets/app-store
python3 build.py
```

`v2/` に 1290 × 2796 の PNG が書き出される。App Store Connect の 6.9 インチ枠にこの 1 サイズを登録すれば、他のディスプレイサイズへは自動で適用される。

文言・傾き・端末の大きさ・オレンジの帯の位置は `build.py` の `SHOTS` で定義している。画像編集ソフトを開かずに調整できる。

## キャプチャの撮り方

- **6.9 インチ相当の端末**（iPhone 16/17 Pro Max 等）で撮る。1320 × 2868 のまま置く
- ステータスバーは写っていてよい。`build.py` が落としてダイナミックアイランドを描き直す
- Pro 限定の画面は Pro が有効なアカウントで撮る

## v1 からの変更方針

`v1` は 2.0.0 以前の UI で、現在のアプリとの乖離が大きい。ガイドライン 2.3 の「アプリを正確に表していない」に触れうるため差し替える。

流入の約 3 分の 2 が App Store 検索経由で、検索結果には先頭 3 枚が並ぶ。先頭 3 枚に差別化を集中させる。

配色・斜めの端末モック・見出しの組み方は `v1` を踏襲する。コンバージョン率が同カテゴリの中央値を大きく上回っており、効いている表現を変える根拠がないため。

## 依存

Pillow とヒラギノ角ゴシック（macOS 標準）。

```bash
pip3 install Pillow
```
