# App Store スクリーンショット

App Store Connect に登録するスクリーンショットと、関連スクリプトを置く。

## ディレクトリ

| パス | 中身 |
| ---- | ---- |
| `v3/` | **現行。App Store Connect に登録する 10 枚** |
| `v1/` | 2026-09 まで公開していた 5 枚。mobile 2.0.0 以前の UI |
| `v2/` | `build.py` で試作した 2 枚。採用しなかった |
| `captures/` | シミュレータで撮った生の画面キャプチャ |
| `swooshes/` | v1 の背景オレンジ曲線を抽出した SVG |
| `build.py` | 生キャプチャに端末フレーム・背景・文言を合成する試作スクリプト |
| `device.py` | `build.py` が使う 3D 風の端末モック描画 |
| `extract_swooshes.py` | v1 の PNG からオレンジ曲線を SVG として抽出する |

`v3` はデザインツールで作成したものを取り込んでいる。`build.py` は端末モックの質感が v1 に届かなかったため採用を見送った。経緯を残す目的で置いている。

## 書き出しの要件

App Store Connect は以下を満たさないと受け付けない。デザインツールからの書き出しでは外れることがあるため、登録前に確認する。

- **1290 × 2796**（6.9 インチ）。この 1 サイズで他のディスプレイサイズへ自動適用される
- **アルファチャンネルを含まない**。全画素が不透明でもチャンネルが存在するだけで弾かれる
- 1 ディスプレイサイズ・1 ローカライズあたり最大 10 枚

確認と修正のコマンドは次のとおり。

```bash
# srgba と出たらアルファが残っている
magick identify -format '%[channels] %wx%h\n' v3/*.png

# アルファを外す
magick 入力.png -background '#2E2E2E' -alpha remove -alpha off 出力.png
```

圧縮サービスは通さないこと。パレット化されて色数が数十まで落ち、階調が崩れる。

## 方針

`v1` は 2.0.0 以前の UI で、現在のアプリとの乖離が大きかった。ガイドライン 2.3 の「アプリを正確に表していない」に触れうるため差し替えた。

流入の約 3 分の 2 が App Store 検索経由で、検索結果には先頭 3 枚が並ぶ。先頭 3 枚に差別化を集中させている。

配色・斜めの端末モック・見出しの組み方は `v1` を踏襲した。コンバージョン率が同カテゴリの中央値を大きく上回っており、効いている表現を変える根拠がないため。

## 依存

Pillow と ImageMagick、ヒラギノ角ゴシック（macOS 標準）。

```bash
pip3 install Pillow
```
